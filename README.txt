ELY SAUNA LEAD GENERATION SITE

Purpose
This site is intentionally framed as demand validation rather than as a finished operating sauna.

Form
The form is configured to send submissions through FormSubmit to adventureinn.mgmt@gmail.com. Make sure this address exists or forwards to the inbox you want to use. The first live submission may trigger a confirmation email from FormSubmit.

Useful validation data collected
1. Local, seasonal resident or visitor
2. Preferred access format
3. Expected usage frequency
4. Optional price comfort
5. Open comments

Images
The site uses a real Adventure Inn property photo supplied by the owner and concept imagery developed for this project. Concept imagery is labelled accordingly because the final sauna unit and placement are not final.

GitHub Pages
Upload index.html, styles.css, script.js, thanks.html and the full assets folder to the root of your repository. In Settings, Pages, choose Deploy from a branch, main, root. Add elysauna.com as the custom domain after deployment.

Recommended decision point
The first useful target is 50 genuine signups. Pay particular attention to local users, repeat use intent, usage frequency, price comfort and private session demand.
